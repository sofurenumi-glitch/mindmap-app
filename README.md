# MindMap — 初期値は、愛

PC / iPhone / iPad で同じURLを開けば同じマップ。Markdownで書いて、Markdownで出す。
シンプルな横ツリーで階層を色分けする、最小構成のマインドマップアプリ。

最終更新：2026-05-24

---

## 使い方（ローカルですぐ動かす）

1. `index.html` をダブルクリックでブラウザで開く
2. 左側のMarkdownエディタを書き換える → 右側のマップが即時更新
3. 右上の「共有」ボタン → URLがクリップボードにコピーされる
4. そのURLをLINEで自分宛に送信 → iPhoneでタップすれば同じマップが開く

ログイン不要。マップのデータはURLの中に圧縮されて入っている。

---

## 操作早見表

| やりたいこと | 操作 |
|---|---|
| 中央テーマを変える | 1行目の `# タイトル` を書き換え |
| 枝を増やす | `- 枝の名前` を追加 |
| 子の枝を増やす | 2スペースインデントして `  - 子の名前` |
| ノードをクリック編集 | マップ上のノードをタップ → ダイアログで編集（空欄保存で削除） |
| 子ノードをワンタップ追加 | ノードにホバー/タップで現れる「+」ボタン |
| マップを共有 | 「🔗 共有」ボタン → URLがコピーされる |
| .mdで書き出し | 「💾 保存」ボタン → `タイトル.md` がダウンロード |
| .mdを読み込み | 「📥 読込」ボタン → ローカルの.mdを開く |
| iPhoneで表示切替 | 左上「⇄ 表示」で エディタ / マップ / 分割 を切替 |

## Markdown記法

両方サポート：

### 箇条書きスタイル（推奨）

```markdown
# 中央テーマ

- 大枝A
  - 小枝A1
  - 小枝A2
- 大枝B
  - 小枝B1
```

### 見出しスタイル

```markdown
# 中央テーマ

## 大枝A
- 小枝A1
- 小枝A2

## 大枝B
- 小枝B1
```

両方同じマップになる。混ぜてもOK。

## データの保管場所

- **URL（ハッシュ部分）**：マップ全体を LZ-String で圧縮して載せている。共有はこれだけで完結。
- **ブラウザのlocalStorage**：そのデバイスで開いていた最新のマップを自動保存。次回起動時に復元。
- **.md ファイル**：「保存」で手元に降ろす。iCloud Drive に置けば全デバイスで参照可能。

## 設計メモ

- 「85点で動く」原則に従って、最初のリリースは **ログイン不要・サーバー不要** に絞った。
- 将来クラウド同期（Supabase）が必要になったら、`saveLocal()` / `loadFromHash()` のレイヤを差し替えるだけで拡張可能な作り。
- 「初期値は、愛」をフッターのスローガンに残してある。マップは情報を整理する道具だけど、その先には常に「気持ちの行き先」がある、という前提を毎回見える場所に置いておく。
